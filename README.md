# TaleTalk — Bolt source edition

This repository contains the TaleTalk application code in a lightweight form so it can be imported into Bolt.

The full-resolution artwork, music, video, and pre-generated voice MP3s remain safely in the original game repository and local project folder. After importing this repository into Bolt, add the required files to `public/` if you need to preview the complete game there.

The production project is unchanged.
